Get started

Install metareview in about a minute.

It runs locally on your machine, inside your own git repository. Pick the path that matches how you work — a command-line tool, or a plugin for your AI coding agent.

Choose your path

Command line

npm

npm install -g metareview
metareview setup --check

The quickest way to get the metareview command. Requires Node.js 18+.

Claude Code

Claude Code plugin

claude plugin marketplace add dsifry/metareview
claude plugin install metareview@metareview

Adds /setup, /review-task-done, /review-pr-ready, /fsm, and more inside Claude Code.

Codex

Codex plugin

codex plugin marketplace add dsifry/metareview
codex

Open /plugins, select the marketplace, and install metareview for the matching $ skills.

From source

Source checkout

git clone https://github.com/dsifry/metareview.git
cd metareview
npm install && npm run build
./bin/metareview setup --check

For development or the latest code. Requires Go 1.26+.

Run your first review.

Use the smallest gate that matches the decision you're making.

# is this branch ready to merge?
metareview review pr-ready --base main

# is this plan good enough to build from?
metareview review artifact docs/spec.md

Each review writes a readable Markdown record into your repo and returns a clear verdict: PASS to proceed, NEEDS_REVISION to fix the cited blockers, or ESCALATED when a human should step in.

Enforce it with git.

Optional — make "review before you push" mechanical, not a habit.

# interactive; --yes headless, --dry-run to preview
metareview setup --install-hooks

Installs deterministic git hooks: git push is blocked until the branch is review-clean (fail-closed; git push --no-verify escapes), and metareview never blocks a commit — its post-commit hook cannot (it runs after the commit); it just names the files it wrote so you review them before pushing. Git invokes the hooks on the real operation, so no spelling of the push command walks around the gate, and pushing a ref that is not the checked-out branch is blocked rather than silently waved through (#82). Install is non-destructive and reversible (--uninstall-hooks); the .gitignore block it adds stays put (remove it by hand).

Pick your reviewer model.

Optional — for the find-and-fix loop and judge calls.

metareview can use Claude, GPT (via Codex), or any OpenAI-compatible provider such as GLM or Kimi. Choose per run with --judge-model:

metareview fsm init --workflow sdlc-loop-proved \
  --base main --judge-model glm-5.3-flash --judge-effort medium

For OpenAI-compatible providers, set OPENAI_BASE_URL and OPENAI_API_KEY; for Codex/GPT it uses your local Codex sign-in. Full details are in the guides below.
