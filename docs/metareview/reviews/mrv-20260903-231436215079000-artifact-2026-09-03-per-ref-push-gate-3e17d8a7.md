## Advisory Findings

- **[mechanical-precision] Preserve deletion binary-independence.** Moving deletion-skip wholesale into the CLI
  would newly require the metareview binary to be present for a pure `git push --delete`, regressing today's
  behaviour (the bash shortcut exits 0 before the binary check) and breaking `TestPrePushSkipsGateOnRefDeletion`.
  Resolution: keep the bash all-deletions shortcut; the CLI still skips deletion lines for a mixed push. Folded
  into spec §3.3 / §4.
- **[completeness] `--pre-push-stdin` is hook-internal.** Reading stdin unconditionally under the flag would
  block on a tty, but only the hook (which always supplies stdin) passes it; a human's `review gate --push`
  never sets it and is unaffected. Documented as hook-internal in spec §3.2; no code guard needed.
