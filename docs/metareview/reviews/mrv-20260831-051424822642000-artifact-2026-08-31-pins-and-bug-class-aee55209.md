## Findings

Round-2 review of the REVISED spec. Two root problems remain UNSOLVED and several fixes RELOCATED holes rather than closing them. Deduped, ranked.

### Blocking — the two deep roots

**R1 (pins) — the proof binds to a diff LINE, not to the fix's BEHAVIOUR.** (feasibility, security) `From`-in-diff proves "a touched line has some tested content," which is strictly weaker than "the fix's new behaviour is tested." Cosmetically touch a pre-existing tested line, or on a genuine fix line pick `To` to mutate pre-existing content — either proves the wrong thing while `Pin.Finding` claims the hard finding. My B1 fix relocated the #24 vacuous-pass one line over. This may be only *mitigable*, not fully closeable: pins deliver "a changed line is guarded by a test" — stronger than the agent's word, weaker than proof. The spec must CLAIM that weaker thing honestly.

**R2 (class) — BugClass is content-addressed when it needs durable identity.** (architecture, data-migration, security, scope, completeness) `BugClass.ID = hash(members)` changes as the confirmed set changes round to round → dissolutions orphaned, `Snapshot.Classes` grows unbounded (the non-termination the pin-clearing fix just cured, reintroduced one layer up); no fix-side field carries the id (the dissolution valve is still unpullable — I added the key without the carrier); `Snapshot.Classes` clears on the agent's *claimed* disposition because the fold has no diff (takes the agent's word — the #1 failure at the class layer); and `FixInstance.Member`+`File` are agent-controlled, so one real edit "answers" every member. The architecture lens' root diagnosis: **this is the same instance-vs-class error, one level up from the one the spec is about.**

### Blocking — tractable

- **R3:** deletion-shaped fixes are unpinnable and B1's own-finding clause gives them no valve — a dead-end absent from the spec's own §4.6 table. (feasibility)
- **R4:** `Snapshot.Unproven` ADD/re-add half unspecified; set-recompute vs temporal-fold ambiguity lets a regressed fix pass `pins_proven` vacuously. (completeness)
- **R5:** near-term rollout (steps 4–5) has the fix agent both define AND answer classes, collapsing the adjudicator/fixer separation; `classes_enumerated` has no `BugClass` to bind to before `classify` (step 6). (security, completeness, scope)
- **R6:** B3 forces answering KNOWN members, not DISCOVERY of unreported siblings; prose oversells "EVERY site / no longer expressible." Compensates, doesn't prevent. (intent)
- **R7:** measurement holes — metric-2 same-file signature is blind to the cross-file class it exists to measure; control-arm intersection is selection-biased; metric-1 needs an undefined cross-round finding id; the classify spike's ground truth was adjusted post-hoc. (testing)
- **R8:** `PinResult.PinID` is redundant with embedded `Pin.ID` — over-scope, drop it. (scope)
