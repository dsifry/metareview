# T2.2 evidence — the §9.7 trajectory monitor (derivable flags) + §9.8 R9 (deferred)

**Task:** T2.2. The §9.7 trajectory monitor watches HOW a fix was produced and raises **advisory**
flags. This ships the two flags derivable from existing artifacts (the reviewed diff + override
records); the §9.8 R9 verbosity flag and the oracle-edit/answer-lookup flags are **deferred** (each is
gated on an undefined baseline / a `⧗` record — see below), not fabricated.
**Spec:** §9.7 (lines 1052–1076), §9.8 R9 (1092–1094). **Depends-on:** T1.3. **Base:** `main`
(`773980a`). Design handoff: `docs/handoffs/handoff-2026-09-01-t2.2-trajectory-monitor.md`.

## What landed (`internal/learning`)

The monitor is a **post-merge `learn` step** (`RunPostMerge` → `ExtractCandidates`), which already has
the reviewed diff and the override-bearing finding records. Two additions:

- **`Input.Diff`** threaded from `source.Git.Diff`; **`Result.Flags []Candidate`** for the monitor's
  advisory flags (reported to a human, never written to repository knowledge); `ExtractCandidates` now
  calls `trajectoryFlags`, and `acceptedMarkdown` renders a **"## Trajectory Flags"** section.
- **`trajectory.go`** with the two flags, both **advisory** (`Kind: trajectory-flag`, `Disposition:
  advisory` — §9.7 is a monitor, not a gate):
  - **`whitespaceOnly(diff)`** — after dropping blank/comment-only lines and collapsing interior
    whitespace, the added and removed CODE lines are identical (both may be empty, e.g. a comment-only
    edit); a change with no diff at all, or a substantive code change (added ≠ removed), does not fire.
    A green suite after such a "fix" is not evidence the bug was addressed.
  - **`selfServed(record)`** — a GRANTED override whose §4.1 requester/granter separation was not
    honored: the same actor on both sides, or a grant with no request at all. A distinct requester AND
    granter does **not** fire. (The grant CLI already refuses a requester who re-grants, `override.go`;
    this catches the residual the CLI cannot — a direct grant on an unrequested finding.)

## Deferred, with rationale (not built)

- **§9.8 R9 verbosity flag — a hidden `⧗`.** "A fix materially larger than the minimal change
  (Guard-and-Go median 1.67×)." There is **no minimal-change / expected-fix-size signal anywhere** in
  the data model (`gitcontext.Context`, `findings.Record`, the `Delta` wire model, the FSM run types);
  the 1.67× is a population median from uncited literature ("cited, not fetched — a gap"), not a
  per-fix baseline. Grounding it requires a maintainer-set proxy/threshold (the same class of decision
  as T4.1's numeric bar) or a reference-patch size added to the model. Deferred with that recommendation.
- **Oracle-edit / answer-lookup flags** — need the deferred `⧗` fix-trajectory record (a new
  additive-optional §2.4 field; schema is itself a build-time decision). §9.7: "the diff/override flags
  do not wait for it." Deferred.

Both are the plan's named mutation-tests ("collapsing `selfServed()`→true or stubbing
`whitespaceOnly()`→true must redden a negative test").

## Tests

- `TestWhitespaceOnly`: whitespace-only and comment-only fire; a substantive change, a pure code
  addition, an empty diff, and a no-op diff do **not** (the load-bearing negatives).
- `TestSelfServed`: same-actor and grant-without-request fire; **two distinct actors do not**; a
  pending (ungranted) request does not.
- `TestTrajectoryFlagsAdvisoryAndDiscriminating`: flags are advisory; a substantive fix with a clean
  (distinct-actor) override raises **no** flags (no over-flagging — the Guard-and-Go failure to avoid).
- `TestExtractCandidatesEmitsTrajectoryFlags`: the flags surface through `Result.Flags`.
