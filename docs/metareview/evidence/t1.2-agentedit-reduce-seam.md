# T1.2 evidence — agentEdit.Reduce seam + gate-can-fail regression

**Task:** T1.2 (Epic E1, Ship 1) — fix the `agentEdit.Reduce` seam so a fix's declared proofs reach
the Delta. **Spec:** §6 chunk 2 (the #24 vacuous-pass: `Reduce` dropped `Pins` → `pins_proven`
vacuously true). **Plan:** T1.2. **Depends-on:** T1.1 (DONE). **Base:** `main`.

## The defect (#24)
`agentEdit.Reduce` returned `run.Delta{Commit: out.(editOut).Commit}` — it dropped everything but the
commit. Any proof a fix declared never reached the `Delta`, so a downstream `pins_proven` gate (T1.3)
would pass on evidence it never saw. A gate can only fail on what reaches it.

## What landed
- `internal/fsm/kind/kind.go`:
  - `editOut` gains `Pins []run.DifferentialProof json:"pins,omitempty"` — the differential proofs a
    fix declares (§9.1; a mutate-a-line pin is the `Kind:"pin"` case).
  - `agentEdit.Decode` bounds the count at `MaxPins` and the canonical size at `checkPayload`; the
    per-proof one-of invariant is already enforced at decode by `DifferentialProof.UnmarshalJSON`
    (T1.1), so a malformed proof is rejected there.
  - `agentEdit.Reduce` now propagates the proofs: `run.Delta{Commit: o.Commit, Pins: o.Pins}`.
