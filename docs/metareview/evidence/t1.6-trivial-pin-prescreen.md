# T1.6 evidence — the §9.8 R7 trivial-pin AST pre-screen

**Task:** T1.6. Reject a semantically-null pin (a mutation that changes only a comment or whitespace)
as `malformed` **before** the break step, so it never surfaces as a phantom `survived`.
**Spec:** §9.8 R7 (lines ~1085-1090), §2.2 (`malformed` widened, ~134-172). **Depends-on:** T1.1, T1.3.
**Base:** `main` (`f6dfb98`).

## What landed

**The pre-screen** (`internal/mutation/prescreen.go`, `semanticallyNull` + `goTokens`). A comment/
whitespace-only mutation compiles and breaks no test, so the break step would score it `survived` (a
blocking unproven-fix) and send the actor to "write a test for a comment" — the wrong signal. R7
rejects it earlier as `malformed`. `semanticallyNull(orig, mutated)` compares the two Go **token
streams** (via `go/scanner` with comments OFF — position-independent and pure): identical streams ⇒ the
change touched only comments/whitespace ⇒ null. If either body fails to scan cleanly it returns
**not-null** (a broken mutation is the compile step's job, not this pre-screen's).

**Wired into `Verifier.verifyOne`** (`internal/mutation/verify.go`) after the baseline-pass check and
before the mutate/compile/run steps: a null mutation returns `PinMalformed` ("…rewrite the pin to
mutate real behaviour"), so it never reaches `survived`/`proven`. `PinMalformed` for a PIN stays
**advisory** (`kind/prove.go` `proofFinding` routes a pin's malformed to non-blocking
`CategoryMalformedPin`; the T1.5 blocking branch is reproduction/deletion only) — exactly R7's intent:
off the `survived` blocking path, onto advisory "rewrite the pin" (and `pins_proven` clause (b) still
refuses a fix that supplied only a trivial pin, so it must be replaced).

**§9.3's three guards** (durable committed test, assertion-not-compile fail-before, untouched-tree-first)
were **already delivered by T1.3 PR-B** (the reproduction engine's classifier + step order); T1.6 adds
the R7 pin pre-screen only.

**Dead code is deferred (honest limit):** a mutation inside `if false {}` or an unused function is NOT
token-identical, so no pure syntactic method flags it, and §9.8/§2.2 state no reachability contract.
The mechanically-guaranteed R7 core is the comment/whitespace (token-identical) case; a dead-code
mutation falls through to the ordinary compile-then-break steps.

## Tests

- `TestSemanticallyNull` (direct, pure): comment-only and whitespace-only → null; a value change and a
  token-count change → not null; an unscannable mutated **or** original → not null (the `!ok` guards).
- `TestVerifyRejectsATrivialCommentPin`, `TestVerifyRejectsATrivialWhitespacePin`: end-to-end through
  `Verify` against a real module + `go test` — both `malformed`, never `survived`.
- Updated `TestOutcomesDistinguishAMalformedPinFromAnUnheldFix`: its "a mutation nothing catches"
  (→ `survived`) row previously used a *comment* mutation — the very phantom R7 now rejects — so it now
  uses a genuinely-semantic-but-uncaught mutation (`n < 10`→`n < 9`, not exercised by the boundary-at-10
  test). The control "a mutation the test catches" (`n < 10`→`n <= 10`) stays `proven`.
