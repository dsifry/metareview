# T1.3 (PR-B) evidence — the reproduction-execution engine (the preferred proof form)

**Task:** T1.3 (Epic E1), PR-B of the agreed two-PR split. PR-A shipped the **pin-fallback**
differential gate; PR-B builds the **preferred reproduction-execution engine** and wires it as the
working proof path (it was stubbed `unverifiable`/fail-closed in PR-A's `prove` node).
**Spec:** §9.1 (execution contract: checkout pre-fix → overlay test-only files → assertion fail-before
→ apply fix → pass-after; the four `PinOutcome` values; `pins_proven` generalizes by clause), §9.3
(anti-gaming: durable committed test, assertion-not-compile fail-before, capture on the untouched tree
first). **Depends-on:** T1.3 PR-A (#39), T0.1 (#38) — both merged. **Base:** `main` (`0457e72`).

## What landed

**1. The reproduction engine** (`internal/mutation/reproduction.go`, `Reproducer`). Same DI style as
the pin `Verifier`, over a **real git worktree** (maintainer-approved). For each proof it:
- **(a)** checks out the **pre-fix** tree (`Snapshot.FixEntryHead`) into a throwaway detached
  `git worktree`;
- **(b)** overlays **only the test-only files** the fix adds or changes (`*_test.go`, helpers
  included, **never** production code) from the **post-fix** tree (`Snapshot.Head`) via `git show`;
- **(c)** runs the **target test** (narrowed by an anchored, regexp-quoted `-run ^<Test>$`) — it must
  **FAIL with an assertion, not a compile/import, error**;
- **(d)** applies the **full fix** — overlays every changed production file and removes every deleted
  file from the post-fix tree, so the worktree now equals `Head`;
- **(e)** re-runs the target test — it must **PASS**.

The **assertion-vs-compile classifier** is the new load-bearing axis (§9.2 ablation: F2P
56.88%→18.84%): the compile check runs **before** the assertion check, so a build-failed run that also
prints `--- FAIL:` from another package is still `malformed`, never accepted as a valid fail-before.
Outcome mapping (the four `run.PinOutcome` values): assertion fail-before + pass-after → **proven**;
pass-before (test gap) or a fix that does not make the test pass → **survived** (blocks); a
compile/import fail-before, an absent target test, or a proof naming no test → **malformed**
(advisory); a missing anchor, worktree/checkout/overlay/exec failure, or an unbuildable post-fix tree
→ **unverifiable** (fail closed). The engine never mutates the repository — every tree is a throwaway
worktree removed afterward. Designed so T1.5's deletion proof reuses the fail-before/pass-after core
(materializing `Head` already removes the deleted span).

**2. `ReproductionProver` + `Provers`** (`internal/fsm/kind/prove_reproduction.go`). `ReproductionProver`
adapts the engine to `Prover.ProveReproductions`, forwarding git through the injected hardened
`gate.Exec` seam — the run's git access arrives here because `ExecInput` carries no git handle.
`Provers` is the production composite: pins → `MutationProver`, reproductions → `ReproductionProver`,
wired at `cli/wiring.go` with `d.Exec`.

**3. `prove` node routing** (`internal/fsm/kind/prove.go`). The `Prover` interface gains
`ProveReproductions`; `ProveSpec` gains `PreFixSHA`/`PostFixSHA` (from `Snapshot.FixEntryHead`/`Head`).
The dispatch routes `run.ProofReproduction` to the reproduction engine (no added-line bind — that is
retired for reproduction and discharged by the §9.2 symptom reviewer, T1.4); pins keep the added-line
bind; **deletion and any unknown kind stay `unverifiable`** (fail closed — deletion is T1.5). A proven
reproduction settles its finding, so `pins_proven` clause (a)'s owed-pin marker is discharged by a
Proven reproduction exactly as by a Proven pin (`settled` keys on any Proven proof kind).

## Scope (unchanged from the two-PR split)
