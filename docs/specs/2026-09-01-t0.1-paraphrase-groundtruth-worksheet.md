## 0. Why constructed, not mined (empirical result)

I mined the **10 persisted runs** (`.metareview/runs/*/audit.jsonl`): **1,412 finding rows → 163
distinct texts across 9 runs.** Clustering found **zero** pairs that an N2 key would merge and **zero**
near-misses (Jaccard ≥ 0.6, differing normalized form). The repeats are **verbatim cross-shard
duplicates of the same review** (11–14× each), not the same fault *reworded across fix rounds*. So the
corpus confirms the spec's premise — **there is no natural paraphrase ground truth to mine** — and also
independently reproduces the **precision** result (163 distinct faults, no accidental merges). The
recall set must therefore be **constructed** by rewording real findings along a principled taxonomy,
which is what this worksheet does. (Precision is measured on the real 163-corpus, unchanged.)

## 1. What a label means

A **group** is a set of finding texts that are the *same underlying fault*. The identity key passes
**recall** if it maps every member of a group to one id, and **precision** if it never maps two
different faults to one id. You are labeling: (a) is each constructed variant a *faithful* same-fault
rewording (belongs in the group), and (b) is each negative control genuinely a *different* fault.

## 2. The paraphrase taxonomy (confirm or amend)

Each class is a way the loop re-words the same fault across rounds. The right-hand column is what the
`(file, normalized-text)` key (spike §4) must do; it is the recall target you set in §4.

| Class | Definition | Key must |
|---|---|---|
| **T1 whitespace/case** | identical wording, different case/spacing/reflow | **always merge** (trivial; N1+) |
| **T2 line/number drift** | same wording, changed line numbers / §refs / counts (code shifted) | **always merge** (N2 collapses digit-runs) |
| **T3 location prefix** | same wording, different/absent `[shard-XX]`/`[cross-shard]` prefix | **always merge** (N3 strips the prefix) |
| **T4 lexical rewording** | same fault, genuinely reworded (synonyms, clause reorder) | **target recall (you set §4)** — the hard, honest one |
| **T5 negative control** | a *different* fault that shares vocabulary / file / line | **never merge** (precision) |

- ✗ Out of scope (bucketed out, spec §4 residual): **same fault, different symptom** — a wholly
  different sentence for the same root cause. No content key can catch it; it is not counted against
  recall.
