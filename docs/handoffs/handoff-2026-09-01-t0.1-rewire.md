## 7. Hard-won gotchas from this session (READ — they cost real time)

- **metareview is a source checkout.** Build/install the CLI: `go install ./cmd/metareview` →
  `/Users/dsifry/go/bin/metareview` (add to PATH, or use `go run ./cmd/metareview`). Version 0.10.0.
- **The pre-finish Stop hook is DISABLED** (`.claude/settings.json` `_disabledHooks`) because
  `metareview status --scope branch` is **unsatisfiable in 0.10.0**: no gate records the `Covered
  paths:` header the check needs, and a repaired NEEDS_REVISION parent isn't superseded by a PASS
  child. Tracked in `docs/tasks/2026-09-01-status-covered-paths-gap.md` (re-enable the hook when that
  lands). The per-task `review task-done`/`pr-ready` gates still work and are the real gate.
- **`run` cannot import `judge`** (cycle) — that's why `identity.go` replicates `NormalizePath`.
- **PR shepherding:** the GTG (`Merge Ready (gtg)`) check is a long-running job (~7–12 min) that waits
  for CI + a **5-min grace window for review bots** that CodeRabbit's rate-limiting can stretch toward
  its 22-min cap — expect slowness. CodeRabbit sometimes posts findings **late** (after a first clean
  look) and submits a formal `CHANGES_REQUESTED` review that resolving threads does not clear — dismiss
  the stale review (`gh api -X PUT .../reviews/<id>/dismissals`) once its threads are resolved. gtg
  fails on any unresolved review thread and flags free-form PR comments as "ambiguous," so keep
  PR-level comments minimal and resolve every thread (fix→reply→resolve, or defer-with-reason→resolve).
- Cursor caught two **real** identity bugs on the freeze (file-alias split, digit placeholder stripped)
  — the rewire will get similar scrutiny; the same-text/different-file regressions per site are exactly
  what protects against them.
